About these previews & sources

Armor appearances follow the client’s item → appearance → display → model and texture links. Helm previews use the Human male variant. Shoulder pieces are shown individually. These are static mesh previews; animated effects and full character assembly are not included.

Creature entries use their client model IDs where internal names have been removed. A new model record does not identify a boss or establish where it spawns. The gallery includes newer creature geometry whose model IDs are absent from the SoD reference build 1.15.9.69722.
